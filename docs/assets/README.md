# Documentation assets

This directory is reserved for sanitized, evaluator-facing screenshots or diagrams that materially improve the submission README.

Before adding an image:

- capture it from the deterministic dashboard fixture or a synthetic demo stream;
- redact license plates, watchlist values, user data, hostnames, tokens, and filesystem paths;
- prefer PNG/WebP under 1600 px wide and keep the file below 1 MB when practical;
- name it descriptively, for example `dashboard-fixture-overview.png`;
- add a short caption and provenance link in the document that uses it.

No unredacted runtime frame or fabricated visual belongs in this folder. The release currently has no committed screenshot asset; the instructions above are the capture contract for the submission team.
