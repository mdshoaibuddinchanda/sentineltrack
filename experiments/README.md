# Experiments

The active runtime does not depend on experiment directories. Historical P11.5 reproducibility scripts and configuration profiles are retained under [`archive/p11_5/`](archive/p11_5/) and [`archive/configs/`](archive/configs/); their reports and registry are preserved under [`reports/p11_5/`](../reports/p11_5/).

New experiments should remain outside the release checkout unless their source, configuration, data provenance, and evaluation artifacts are intentionally promoted into the tracked submission package.
